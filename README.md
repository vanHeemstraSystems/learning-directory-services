Learning Directory Services

## Directory Services & LDAP
CISSP Domain: Domain 5 - Identity and Access Management (IAM)

### Learning Objectives:
	•	Master directory services architecture
	•	Understand LDAP protocol and operations
	•	Learn Active Directory fundamentals
  
### Study Topics:
	•	Directory Information Tree (DIT) structure
	•	LDAP protocol operations and security
	•	Microsoft Active Directory architecture
	•	OpenLDAP and other directory solutions
	•	Directory synchronization and federation
  
### Assignment:
Set up a virtual lab with OpenLDAP or Active Directory. Create an organizational unit structure, add 50+ users across different departments, and implement group-based access controls. Document the schema design and security configurations.
